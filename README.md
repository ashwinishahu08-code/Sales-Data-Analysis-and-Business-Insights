# Sales Data Analysis and Business Insights

## Project Overview
This project focuses on analyzing sales data to identify business trends, evaluate sales performance, and generate meaningful insights using Python, SQL, and Microsoft Excel.

## Objectives
- Analyze overall sales and profit performance.
- Identify top-performing product categories.
- Compare sales across different regions.
- Understand monthly sales trends.
- Create an interactive Excel dashboard to present key business metrics.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL (SQLite)
- Microsoft Excel
- Google Colab

## Dataset
The project uses a sample sales dataset containing 500 sales records and 14 columns, including order date, region, category, product, quantity, sales, profit, and payment mode.

**Note:** This is a synthetic practice dataset created for learning and portfolio demonstration. It does not represent actual company transactions.

## Key Performance Indicators
- Total Sales: ₹46,21,122
- Total Profit: ₹12,69,395.11
- Total Orders: 500
- Average Order Value: ₹9,242.24

## Analysis Performed
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Product and category performance analysis
5. Regional sales and profit analysis
6. Monthly sales trend analysis
7. Data visualization
8. SQL queries for business analysis
9. Excel dashboard creation

## Dashboard
The Excel dashboard presents:
- Sales by Product Category
- Sales by Region
- Monthly Sales Trend
- Profit by Region
- Key Performance Indicators (KPIs)

- `Sales_Data_Analysis.ipynb` – Python analysis notebook

This project demonstrates practical skills in data cleaning, exploratory data analysis, SQL querying, data visualization, and dashboard development to support data-driven business insights.
